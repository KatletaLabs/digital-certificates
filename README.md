## About this record

Documents are grouped by issuer under `certificates/<issuer>/` and named `YYYY-MM-DD-course-name.pdf`. Only earned credentials are listed.

Course completions use **Completed**; digital badges use **Earned**. Professional certifications will be identified separately, with **Active** or **Expired** status only when supported by the issuer's validity dates.

Original PDF files are preserved without modification. [SHA-256 checksums](SHA256SUMS) provide a file-integrity reference; they do not independently authenticate the issuer.

<details>
<summary>Verify the local PDF checksum</summary>

From the repository root on Linux:

```bash
sha256sum -c SHA256SUMS
```

</details>
